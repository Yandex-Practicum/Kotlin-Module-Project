# Пустой репозиторий для работы с Kotlin кодом в Android Studio
Классы: 
- В мейне просто основной цикл приложения
- В GeneralLogic общий код для команд и их считывание
- В NotesArchive все, что нужно для существования архива
- в Note все, что нужно для существования заметки 

Логика класса  GeneralLogic:
- Есть определенный набор команд в функции command, затем choiceCommand дает выбрать команды в зависимости от того, на каком "уровне" находится пользователь
- Функция exit для шага назад или выхода из приложения 
- Функция createArchiveOrNote отвечает за процесс архива/заметки 
- Функция showList показывает списки созданных архивов/заметок
- Фунция open дает возможность пользователю либо выбрать("открыть") архив, либо заметку и затем посмотреть ее содержимое 
- Функция readInt отвечает за ввод пользователя, обработку этого ввода и заставляет пользователя ввести корректные данные

!Особенность: 1) Я рассматриваю уровень Архивов как главное меню, а не как Архивы. В главном меню есть возможность как создать архивы, так и посмотреть их. 
                 Просто в примере пишут "выбор архива выглядит так" и там же дают возможность создать архив или выйти из приложения. На мой взгляд это некорректно, ибо выбирать архив надо только из списков.
              2) Если пользователь вводит пробелы в именах или содержании записки - я считаю это как пусто.
