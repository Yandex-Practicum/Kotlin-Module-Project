# 📝 Заметки

Простое консольное приложение для ведения заметок на Kotlin.

## Что умеет

- 📁 Создавать архивы (папки для заметок)
- 📝 Добавлять заметки с названием и текстом
- 👀 Просматривать созданные заметки
- 🔙 Возвращаться назад из любого меню

## Как запустить

1. Откройте проект в IDE
2. Запустите `Main.kt`
3. Следуйте инструкциям в консоли

## Как пользоваться
СПИСОК АРХИВОВ

**Создать**

**Выход**

**Список:**

2. Рабочие заметки
3. Личные заметки

**Выберите пункт меню:**

- **0** - создать новый архив/заметку
- **1** - выйти/вернуться назад
- **2, 3...** - выбрать существующий архив/заметку
## Особенности

- ✅ Нельзя создать пустые названия
- ✅ Проверка ввода на ошибки
- ✅ Простая и понятная навигация
